자바스크립트는 배열을 다루는 다양한 메서드를 제공합니다.

그 중에서 배열을 좀 더 우아하게 사용하도록 돕는 `.every()`와 `.some()` 두 가지 메서드에 대해 알아보겠습니다.

[MDN 문서로 .every() 확인하기](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array/every)

[MDN 문서로 .some() 확인하기](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array/some)

#### .every()

`.every()`는 배열의 모든 요소가 조건을 통과하는지 검사하며, 모든 요소가 조건을 통과하면 true를 반환합니다. 하나 이상의 요소가 조건을 통과하지 못하면 false를 반환합니다.

예를 들어, 다음과 같이 사용할 수 있습니다.

```angelscript
const numbers = [1, 2, 3, 4, 5];
const isAllNumbersGreaterThanZero = numbers.every(num => num > 0); // true
const isAllNumbersEven = numbers.every(num => num % 2 === 0); // false
```

위 코드에서 isAllNumbersGreaterThanZero 변수는 true가 됩니다. numbers의 모든 요소가 0보다 크기 때문입니다.

반면에 isAllNumbersEven 변수는 false가 됩니다. numbers의 모든 요소가 짝수가 아니기 때문입니다.

#### .some()

`.some()`은 배열의 요소 중에서 적어도 하나의 요소가 조건을 통과하는지 검사하며, 어떤 요소라도 조건을 통과하면 그 즉시 true를 반환합니다. 모든 요소가 조건을 통과하지 못하면 false를 반환합니다.

예를 들어, 다음과 같이 사용할 수 있습니다.

```angelscript
const numbers = [1, 2, 3, 4, 5];
const isSomeNumberGreaterThanFour = numbers.some(num => num > 4); // true
const isSomeNumberEven = numbers.some(num => num % 2 === 0); // true
```

위 코드에서 isSomeNumberGreaterThanFour변수는 true가 됩니다. numbers 배열에서 4보다 큰 요소가 적어도 하나 존재하기 때문입니다.

마찬가지로 isSomeNumberEven 변수도 true가 됩니다. numbers 배열에서 짝수를 나타내는 요소가 적어도 하나 존재하기 때문입니다.

#### 예제

`.every()`와 `.some()`을 사용하여 배열에서 특정 값이 존재하는지 검사해보겠습니다.

```javascript
const items = ['avocado', 'banana', 'orange', 'cherry'];
const keyword = 'orange';

const isItemsEveryOrange = items.every(item => item === keyword); // false
const hasOrange = items.some(item => item === keyword); // true
```

다음으로는 배열의 요소들이 모두 같은 타입인지 검사하는 예제를 소개하겠습니다.

```javascript
const numbers = [1, 2, 3, 4, 'five'];
const isAllNumbersEvery = numbers.every(num => typeof num === 'number'); // false
const isAllNumbersSome = numbers.some(num => typeof num === 'number'); // true
```

#### 결론

이 함수들 없이도 자바스크립트에서 배열을 다루는데 전혀 지장이 없습니다. 하지만, 이렇게 강력한 기능으로 배열을 손쉽게 검사하고, 판별할 수 있다는 것을 확인할 수 있습니다. 여기에서 그치지 않고, 이 둘을 더 다양한 검사 도구로써 활용할 때 자바스크립트의 강력함을 느낄 수 있을 것이라고 생각합니다.
