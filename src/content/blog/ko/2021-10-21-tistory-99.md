## 05 스마트폰 회전을 사용한 레이아웃을 만들어 봅시다. 아이폰의 기본 ...

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        *{
            margin: 0;
            padding: 0;
        }
        li{
            list-style-type: none;
        }
        @media screen and (orientation : portrait) {
            div.left{
                display: none;
            }
        }
        @media screen and (orientation : landscape) {
            div.left{
                width: 30%;
                float: left;
            }
            div.right{
                width: 70%;
                float:right;
            }
        }
        div.content{
            padding: 16px;
        }
        li{
            padding: 24px 0px 24px 0px;
            border-bottom: 1px solid #c7c7c7
        }
    </style>
</head>
<body>
    <div>
        <div class="left">
            <div class="content">
                <h1>List</h1>
                <ul>
                    <li>첫번째 리스트 입니다.</li>
                    <li>두번째 리스트 입니다.</li>
                    <li>세번째 리스트 입니다.</li>
                    <li>네번째 리스트 입니다.</li>
                    <li>다섯번째 리스트 입니다.</li>
                </ul>
            </div>
        </div>
        <div class="right">
            <div class="content">
                <h1>제목제목제목</h1>
                <p>텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트</p>
                <p>텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트</p>
                <p>텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트</p>
                <p>텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트텍스트</p>
            </div>
        </div>
    </div>
</body>
</html>
```
