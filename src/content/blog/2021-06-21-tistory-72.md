## 08 **다음 입력 양식을 만드시오.**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>연습문제8</title>
</head>
<body>
    <b>시작 그룹</b>
    <br/>
    <input type="radio" name="startGroup" checked />새 탭 페이지 열기<br/>
    <input type="radio" name="startGroup" />중단한 위치에서 계속하기<br/>
    <input type="radio" name="startGroup" />특정 페이지 또는 페이지 모음 열기<br/><br/>
    <b>개인정보 및 보안</b><br/>
    <input type="checkbox" name="infoSecu" checked />동기화 및 서비스<br/>
    <input type="checkbox" name="infoSecu" checked />로그인 허용<br/>
    <input type="checkbox" name="infoSecu" />페이지 미리 로드
  </body>
</html>
```

      </tr>
