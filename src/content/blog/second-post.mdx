## useState란

React에서 컴포넌트의 **로컬 상태**를 관리하는 가장 기본적인 Hook입니다.
함수형 컴포넌트가 렌더링 사이에 값을 기억할 수 있게 해줍니다.

```tsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button type="button" onClick={() => setCount((c) => c + 1)}>
      Count: {count}
    </button>
  );
}
```

## MDX에서 React 컴포넌트 사용하기

MDX 파일 상단에서 React 컴포넌트를 import하고, hydration directive와 함께 사용합니다.

```mdx
import InteractiveDemo from '../../components/react/interactive-demo.tsx';

<InteractiveDemo client:visible />
```

## TypeScript와 함께

상태의 타입을 명시하면 더 안전한 컴포넌트를 작성할 수 있습니다.

```typescript
type DemoState = {
  count: number;
  name: string;
};

function useDemoState(initial: DemoState) {
  const [state, setState] = useState<DemoState>(initial);
  return [state, setState] as const;
}
```
